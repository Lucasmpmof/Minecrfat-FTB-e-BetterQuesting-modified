# Objetivo

Criar um questbook totalmente compatível com meu modpack, utilizando como base os melhores questbooks da comunidade, adaptando-os para uma progressão linear, intuitiva e voltada para jogadores iniciantes.

O objetivo não é copiar um modpack existente, mas criar uma experiência própria que ensine os mods presentes de forma organizada e divertida.

---

# Objetivos Principais

- Ensinar todos os mods do modpack.
- Manter uma progressão natural.
- Evitar excesso de checkmarks.
- Explicar conceitos ao invés de apenas pedir itens.
- Integrar tecnologia, magia e exploração.
- Traduzir completamente o questbook para português.
- Manter compatibilidade total com FTB Quests.

---

# Filosofia

Este questbook deve funcionar como um guia de aprendizado.

Cada quest deve ensinar pelo menos uma destas coisas:

- Um conceito novo.
- Uma mecânica importante.
- Um bloco.
- Uma máquina.
- Um objetivo.
- Uma integração entre mods.

Quests que apenas pedem para fabricar itens sem ensinar nada deverão ser evitadas.

---

# Público-alvo

Este questbook será desenvolvido principalmente para jogadores que:

- nunca jogaram Modded;
- conhecem poucos mods;
- desejam aprender naturalmente;
- gostam de exploração;
- preferem uma progressão organizada.
